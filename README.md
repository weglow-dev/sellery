# Sellery — 인플루언서 공동구매 중개 플랫폼 프로토타입

브랜드사와 인플루언서(셀러)를 잇는 공동구매 중개 플랫폼 **셀러리(Sellery)** 의 클릭 가능한 UI/UX 프로토타입입니다.

**라이브 데모** → https://junho763-dotcom.github.io/sellery-prototype/

단일 `index.html` (의존성 없음, 정적 호스팅). 마스터 모드로 인플루언서 센터 / 브랜드 센터 / 관리자 창구 / 고객 화면을 탭으로 전환하며 전체 플로우를 테스트할 수 있습니다. `login.html`은 이메일 기반 파트너(인플루언서·브랜드) 로그인 데모입니다.

### 센터 고정 링크

| 링크 | 화면 |
|---|---|
| `index.html#influencer` | 인플루언서 센터만 |
| `index.html#brand` | 브랜드 센터만 |
| `index.html#admin` | 관리자 창구만 |
| `index.html#customer` | 고객 판매센터만 |
| `index.html#s/c1` | 판매 링크 진입 (링크 보호 모드) |

## 구현된 플로우

상품 등록 → 검수 → 샘플 요청/승인/배송/테스트 → 공구 일정 제안/승인(등급 우선 기간제 캘린더) → 기간 한정 링크 → 판매(실시간 매출) → 종료 → D+21 교환·환불 기간 → 브랜드/셀러 정산 → 재공구

## 주요 기능

- 캠페인 스레드 (채팅 + 시스템 이벤트 타임라인, 연락처 유출 감지, 고객 CS는 브랜드 직결)
- 인플루언서 갤러리 + 브랜드의 공구 직접 제안(역제안, 수락/거절)
- 익명 셀러 스카우트 (유료 레퍼런스 열람 → 제안 수락 시 신원 공개 + DM)
- 셀러 등급/랭킹 (3개월 확정 매출 기준 7등급, 등급 추가 수수료 최대 +3%p, 익명 리더보드)
- 등급 우선 기간제 — 기간은 누구나 열되, 플래티넘 이상이 확정한 기간엔 플래티넘 이상만 진입
- 링크 진입 보호 — 인플루언서 링크로 온 고객에게 경쟁 상품 미노출 (새로고침·재방문에도 유지)
- 실시간 매출 대시보드 (7일 차트, 주문 피드, 판매 시뮬레이션)
- 발주서 CSV 다운로드 / 이메일 자동 발주 (시뮬)
- 정산 시뮬레이션 — PG 1.9% / 플랫폼 10% / 인플루언서 수수료(브랜드 제안 요율 + 등급 추가분) / 개인 원천징수 3.3%, D+21 에스크로 자동 정산
- 셀러리(🥬) 포인트 경제 (데이터 열람, 상단 노출, 샘플 결제)

데이터는 브라우저 localStorage에 저장됩니다. 우측 상단 "데이터 초기화"로 시드 데이터로 리셋.

> 프로토타입 전용 — 실제 결제·인증·서버 없음.
